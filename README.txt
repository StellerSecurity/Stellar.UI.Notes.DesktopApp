STELLAR NOTES DESKTOP

Stellar Notes is a notes app for Windows, macOS and Linux, with rich-text
editing, offline notes and cross-device sync through Stellar ID.
Built with Electron, Angular and Quill.

BUILD

Requires Node.js 24 and the project's reviewed, locked dependencies.

  Windows:  npm run electron:winBuild
  macOS:    npm run electron:macBuild
  Linux:    npm run electron:linuxBuild

Packages are written to dist/. macOS release builds require signing credentials.
